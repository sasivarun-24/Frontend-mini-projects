# Pokemon Finder 🔴⚪

A bright, fun web application that fetches and displays Pokemon sprites right to your screen using the PokeAPI!

## Features
- **Live PokeAPI Search:** Type in any Pokemon's name and hit fetch to instantly get their image directly from the official [PokeAPI](https://pokeapi.co/).
- **Pokedex Aesthetic:** Features a custom CSS styling inspired by a classic Pokedex, including a red/white theme, a bouncing animation for the returned sprite, and stylish buttons.
- **Async Data Fetching:** Utilizes modern JavaScript `async/await` and the `fetch` API for smooth, fast background requests.

## Technologies Used
- HTML5
- CSS3 (Custom styling and CSS animations)
- Vanilla JavaScript (DOM manipulation)

## How to Run
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/sasivarun-24/pokemon-api-finder.git
   ```
2. Open `index.html` in your web browser.
3. Type a Pokemon name (like *pikachu*, *charizard*, or *gengar*) into the search bar and click **fetch pokemon**!
