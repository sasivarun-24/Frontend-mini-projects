# Rock Paper Scissors ✊✋✌️

A fun, interactive Rock, Paper, Scissors game that you can play directly in your web browser.

## Features
- **Play Against the Computer:** Choose your move and see if you can beat the computer's randomized selection.
- **Dynamic Score Tracking:** Keeps a running tally of both the player's and the computer's wins.
- **Visual Feedback:** Instant text updates with color-coded results (green for a win, red for a loss) for quick feedback.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (DOM manipulation)

## How to Play
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/sasivarun-24/rock-paper-scissors-js.git
   ```
2. Open `index.html` in your web browser.
3. Click on the 👊, ✋, or ✂️ buttons to make your move!
