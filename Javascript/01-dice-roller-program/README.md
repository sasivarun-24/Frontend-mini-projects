# JS Dice Roller 🎲

A simple, interactive web app that simulates rolling three dice simultaneously.

## Features
- **Instant Rolls:** Click the "roll" button to immediately generate three random numbers.
- **Fair Simulation:** Randomly generates numbers between 1 and 6, simulating the exact behavior of standard six-sided dice.
- **Clean Interface:** A straightforward, focused UI built entirely with HTML and CSS styling.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (`Math.random()` and DOM manipulation)

## How to Play
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/sasivarun-24/js-dice-roller.git
   ```
2. Open `index.html` in your web browser.
3. Click on the **roll** button to see what you get!
